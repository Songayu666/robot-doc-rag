# robot-doc-rag

A deployable retrieval-augmented generation service for robot manuals and technical documents.

## Planned stack

- Python 3.12
- FastAPI and Pydantic
- PostgreSQL and pgvector
- Redis
- Docker Compose
- pytest

## Status

Initial project scaffold. The first milestone is a tested FastAPI backend with document upload, task tracking, PostgreSQL persistence, Redis progress updates, and SSE streaming.
